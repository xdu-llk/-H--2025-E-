## 一、功能缺失（要写代码的）

### 1. 上电找靶 ⭐

**问题**：开机时 `yaw_ref = 0`（锁在开机朝向）。如果靶纸不在视野里，
视觉一直报 `status = 0` → `err_valid = false` → **云台永远不动，也就永远找不到靶**。

**做法**：开机后先进入搜索模式，扫到靶纸再切正常闭环。

### 2. 丢靶后找靶 ⭐

**问题**：现在丢靶 = `err_valid = false` → `yaw_ref` 冻结 → **原地死等**。

| 丢靶场景 | 现在能恢复吗 |
|---|---|
| 人走过遮挡 | ✅ 能（靶纸没动） |
| 光照突变 | ✅ 一般能 |
| **车转弯太快，靶纸出视野** | ❌ **不能** |

**做法**：按最后已知方向外推一段时间，超时则放弃（或反扫）。

### 3. 视觉端：丢靶时发最后有效的 err_x

**这是 1、2 的**前置条件**。**

现在 [camera_display.py:1612](../rectangle/camera_display.py#L1612) 丢靶时发 `err_x = 0`：

```python
serial_dev.write(build_uart_frame(STATUS_NO_TARGET, 0))
```

**⇒ 主控连"靶纸往哪边出去了"都不知道，搜索无从下手。**

**做法**：丢靶时发**最后一次有效值**（或用符号位表示出去的方向）。

## 二、搜索机制设计（1 + 2 共用）

**核心：扫描就是"人为地推 `yaw_ref`"，和视觉推是同一个机制。**

```c
if (需要搜索) {
    yaw_ref += SCAN_RATE * SEND_PERIOD_SEC;     /* 固定速率推 */
}
/* 一旦 status = VALID → 立刻切回正常闭环 */
```

### 参数

| 参数 | 建议初值 | 说明 |
|---|---|---|
| `SCAN_RATE` | 0.5 rad/s ≈ **30°/s** | 太慢找不到，太快检测跟不上（有运动模糊） |
| 捕获确认 | **连续 3 帧** status=VALID | 防误检 |
| 扫描范围 | ❓ **取决于云台能不能无限旋转** | 有限位就得往返扫 |

### ⚠️ 未确认的前提

**云台是不是无限旋转结构（有没有导电滑环）？**
- 能无限转 → 单向扫一圈就行
- 有限位 → 要往返扫，而且不能在限位处顶死
