# 工程说明 — 一维云台激光瞄准

> 2025 电赛 E 题「简易自行瞄准装置」的**实验室招新改编版**：循迹小车 + 车载一维云台激光瞄准。
> 本工程**只做云台以上部分**（视觉 + 瞄准）；循迹、电机、定点停车归**底盘主控**，不在本工程里。

## 1. 这套东西要干什么

小车沿椭圆赛道顺时针跑，车上一个小云台负责把激光打到赛道中央的竖直靶线上。

| 项 | 内容 |
|---|---|
| 赛道 | 椭圆：直道 1.5 m + 弯道半径 0.5 m，顺时针，四个标记点 1→2→3→4→1 |
| 靶 | 赛道中央的**一条竖直中线** ⇒ 只需**一维偏航**瞄准 |
| 要求 | ① 一圈 ≤ 20 s ② 识别数字 N 并定点停车 ③ 任意姿态 2 s 内击中竖线 ≤ 3 cm ④⑤⑥ 在 2→3、4→1 段**行进中**打靶 ≤ 5 cm |

本工程负责其中的**视觉识别 + 云台瞄准**。

## 2. 三块板

| 板 | 型号 | 职责 |
|---|---|---|
| 主控 | **MSPM0G3507（立创·天猛星）** | 云台控制、陀螺读取、激光开关、调试输出 |
| 视觉 | **MaixCam2**（跑 MaixPy） | 认数字、找靶纸、算 `err_x`，发给主控 |
| 底盘主控 | 另一块板 | 循迹、电机、定点停车（**不在本工程**） |

> ⚠️ 主控**不是 TI LaunchPad**。`LP-MSPM0G3507` 的排针布局与本板完全不同，照抄会得到"能编译但引脚全错位"的固件。本工程引脚一律以 `empty.syscfg` 为准。

### 接线

```
UART0  PA10/PA11  →  USB-TTL            调试打印，115200 8N1
UART1  PA8 (TX) / PA9 (RX)  →  QD4310 云台电机
UART2  PB17(TX) / PB18(RX)  →  汇电籽-601 陀螺模块      ⚠️ PB17 必须接
UART3  PB2 (TX) / PB3 (RX)  →  MaixCam2 的 A22 / A21
激光   PA2        →  激光笔 MOS 管栅极               高 = 开
```

```
QD4310  T(TX) → PA9    R(RX) ← PA8    G → GND    XT30 → 24V
陀螺    T(TX) → PB18   R(RX) ← PB17 ← 必须接！  V → 5V  G → GND（3.3V 电平直连）
MaixCam A21(TX) → PB3  A22(RX) ← PB2
```

**MaixCam2 侧**：视觉串口 A21(TX)/A22(RX) = `UART4` ↔ MSPM0；底盘串口 A30(TX)/A31(RX) = `UART1`（只发不收）。设备名规律 **`UARTn` → `/dev/ttySn`**。

⚠️ 排针 `5V` 与 USB VBUS 是**同一电节点** ⇒ USB 调试和外部灌 5V **只能二选一**；整车从主电源取 5V 时**必须与 24V 共地**。

## 3. 实现方案

```
速度指令(0x04, rad/s) = 几何前馈 + 视觉 P          两路同量纲，直接相加
```

云台是**开环**的：只发速度指令，不读云台角度。整个控制靠下面两条腿站起来：

**① 几何前馈（`guidance.c/h`）**
陀螺测的是**车体**偏航角 ψ，用它反推车在椭圆弧上的位置，再算出"靶方位角的变化率"，作为前馈量。

> 为什么必须有它：QD4310 的"速度"是**转子相对定子**的转速，而定子固定在车架上。车头自己转的那一份如果不用前馈扣掉，云台就会跟着车头一起跑。

**② 视觉 P（`empty.c`）**
`w += AIM_GAIN_RATE × err_x`（`err_x` 经 2 态卡尔曼滤波）。负责收拾静态残差。

> 陀螺装在**车体**上，不测云台 ⇒ **没有速率自稳环**。云台自身靠 QD4310 内部速度环稳。

**时序**
- **开机**：`清错误(0xFB) → 使能(0x01) → 回零(0x05→0°)`，等 500 ms 再放行瞄准（否则第一条 `0x04` 会把回零的位置环半路切走）。
- **平时**：收到新视觉帧就立刻发（事件驱动，延迟 0~1 ms）；`5 ms` 只在视觉断流时兜底。⚠️ 速度模式补帧**不能发 `0x00`**（那是"保持上一拍速度"），要发就显式发 0 速度。
- **进弯**：角速度超阈值时用 `0x05` 绝对角定位 300 ms 校准一次，之后交棒给前馈+视觉。

**几何常量**：`GEO_R_PATH=0.5`（车到半圆圆心）· `GEO_R_TGT=0.75`（靶到圆心）· `GEO_DELTA0_LEFT=-90°` / `RIGHT=+90°`。目标量是 dθ/dt，与坐标系无关，两个半圆通用。

⚠️ **上电必须把车摆正**：ψ 是**相对开机朝向**的角度，几何公式默认"ψ=0 时车在『直道→左弯』切点、车头正对 +x"。摆错位置 ⇒ 前馈整体偏一个常数 ⇒ 云台匀速漂。比赛流程（车停在两弯之间的直道端点）正好满足这个位姿。

## 4. MaixCam2 侧程序（`rectangle/`）

入口 `main.py` → `no_canny.py`，三个阶段：

```
① 相机切 416×416 → YOLOv5 数字模型（最多 10 s）→ 连续多帧同一数字才算认出
② 把数字 N 发给底盘（重复 3 s，不等 ACK）→ 相机切回 416×260
③ 矩形识别瞄准，每帧把 err_x 发给云台，跑到底
```

| 要点 | 说明 |
|---|---|
| **为什么要切分辨率** | 数字模型要 416×416 方形；矩形那套阈值**全按 416×260 标定**，换分辨率就作废 |
| **切回后不重锁曝光** | ISP 不会重置，`EXPOSURE_US = 5000` 只在开机锁一次 |
| **标签陷阱** | 模型 `labels = ["3","1","2","4"]`，必须用 `labels[class_id]` 反查，**别写 `class_id+1`**（会把 3 当 1，停错点位） |

✅ 两阶段流程已在车上实测通过（2026-10-04）：切分辨率、认数字与发 N、切回 416×260 后矩形识别均正常。

## 5. 通信协议

### 云台 QD4310（UART，115200 8N1，设备 ID 0，固件 Software 6.4.0）

UART 包 = `[ID] + [CAN 包原样] + [CRC8]`

- 控制包 **5** 字节：`ID, 指令, 控制量(2 字节小端), CRC8`
- 反馈包 **10** 字节：`ID, 电机状态, 错误码, 电流(2), 转速(2), 角度(2), CRC8`
- **CRC8**：多项式 `0x07`、初值 `0x00`、异或 `0x00`、不反转。手册没写覆盖范围，本工程按"包内 CRC 之前的全部字节"处理。
- **指令码**：`0x01` 使能 · `0x02` 失能 · `0x03` 电流 · `0x04` 速度 · `0x05` 角度 · `0x06` 低速 · `0x07` 角度步进 · `0xFB` 清错误 · `0xFE` 置零 · `0xFF` 重启

| 指令 | 类型 | 换算 | 满量程 |
|---|---|---|---|
| `0x05` 角度控制 | uint16 | `raw = θ/(2π) × 65535` | 65535 |
| `0x07` 角度步进 | int16 | `raw = Δθ/(2π) × 32767` | ±32767 |
| `0x04` 速度 | int16 | `raw = rpm/1000 × 32767` | ±32767 |
| `0x03` 电流 | int16 | `raw = A/10 × 32767` | ±32767 |

⚠️ **一发一收**：发一条 → 等反馈或超时 → 才能发下一条，**严禁收发异步**。
⚠️ **`0xFE`（置零）绝对不能发** —— 会覆盖厂家上位机标定的零点（要清错误只能发 `0xFB`）。

**电机内部环**（厂家上位机改的，存在电机里，**不在代码里**；改完必须点「储存」否则断电回原值）：角度环 `kp=150 ki=0 kd=0`；速度环 `kp=0.030 ki=0.39 kd=0`。速度环 ← 平时 `0x04` 瞄准；角度环 ← 进弯 `0x05` 一次定位。

### 陀螺 汇电籽-601（ICM42688，UART 115200 8N1，3.3V 直连）

帧 `AA 55 | DevID(0x60) | CMD | LEN | DATA... | CS`，**CS = (DevID + CMD + LEN + DATA各字节) & 0xFF**（从 DevID 起算，**不含 `AA 55`**）

- **回报率 100 Hz，固件写死**（协议里没有任何设置频率的指令）。
- 本工程用**全数据模式**（带原始角速度 GyroZ）。开机发 `设全数据模式 AA 55 60 0B 01 00 6C` → `启动上报 AA 55 60 0A 01 01 6C`。
- ⚠️ **模块默认不上报，靠这条开机指令叫醒** ⇒ `PB17` 不接就永远是 0 帧。

### 板间

**MaixCam2 → MSPM0（视觉，每帧）**：`AA 55 | STATUS | ERR_X_LO | ERR_X_HI | CHECKSUM` 共 6 字节
`STATUS` 1=检测到靶纸 0=未检测 · `ERR_X` int16 小端有符号 = **靶心 − 激光点**(px) · `CHECKSUM` = **前 5 字节之和** & 0xFF（**含帧头**，与陀螺协议相反）

**MaixCam2 → 底盘（数字 N）**：`AA 55 | 'N'(0x4E) | DIGIT | CHECKSUM` 共 5 字节
`DIGIT` 1~4，**0 = 没认出来** · `CHECKSUM` = 前 4 字节之和 & 0xFF · 确认后**重复发 3 秒**（20 Hz，60 次），**无 ACK**
