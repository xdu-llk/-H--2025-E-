# my_ti_control — 一维云台激光瞄准

2025 电赛 E 题「简易自行瞄准装置」的**实验室招新改编版**：寻迹小车 + 车载一维云台激光瞄准。

**本工程只做云台以上部分**（视觉识别 + 云台瞄准）。循迹、电机、定点停车归**底盘主控**，不在本工程里。

| 板 | 型号 | 职责 |
|---|---|---|
| 主控 | MSPM0G3507（立创·天猛星） | 云台控制、陀螺读取、激光开关 |
| 视觉 | MaixCam2（MaixPy） | 认数字、找靶纸、算 `err_x` |
| 底盘主控 | 另一块板 | 循迹 / 电机 / 定点停车（不在本工程） |

**方案一句话**：云台开环，速度指令 `(0x04, rad/s) = 几何前馈(陀螺测车体偏航 ψ 反推靶方位角变化率) + 视觉 P(err_x 经卡尔曼)`。陀螺装在车体上，没有速率自稳环。
